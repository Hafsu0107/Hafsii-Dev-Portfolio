HOW TO USE
1. Put the SVG files in your project assets/images folder.
2. Use logo-hafsii-dev.svg in the navbar.
3. Use side-developer-illustration.svg on the right side of the hero.
4. Use background-grid-glow.svg as a subtle hero/section background.
5. Replace project placeholders with your real project screenshots.
6. Keep the blue accent mostly for buttons, links, borders, icons and highlights.
7. For the final portfolio, use your real photo if you want a personal-photo version.
